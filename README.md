## 优惠码怎么填：从选套餐到结账

流程不复杂，但顺序错了会白忙。

1. **先在购物车里把配置选完整**。洛杉矶、硬件代次（AS3 / AN4 / AN5）、网络（Premium / Eyeball / Tier 1）、具体型号，一步步选。有些型号页面上显示"暂无库存"，那就是真的选不了。
2. **选计费周期**。这一步直接决定你能用哪个码。年付能过的码，月付大概率过不了。
3. **回到购物车，找到 Promo Code / 优惠码输入框**，填进去，点 **Validate Code**。
4. **看提示**。通过了会显示折扣后的金额；提示无效，一般就是三件事之一：周期不对、产品线不对、活动已经结束。

有个细节要注意：账户金返还不是直接抵这次账单。它是按周期分批打到你的账户余额里（10% 那档分 12 个月返还）。所以对比"15% 折扣 + 10% 返还"和"20% 折扣"哪个划算，得看你打算用多久——第一年现金支出少 20% 的那档更直接，长期续费的话循环折扣才是主角。

**流量超了会停机吗？** 不会。洛杉矶这几条线都是达量限速、不限流量。Pro 的 TINY / Pocket / STARTER 限到 4Mbps，MINI / MICRO 是 8Mbps，MEDIUM 及以上 10Mbps；T1 的限速档位更高，V4C8G 以上能保留 500Mbps。这一点对跑长期业务的用户比价格更重要。

**优惠码能叠加吗？** 不能。一个订单只能用一张，而且多数码本身就限定了产品线和周期。
